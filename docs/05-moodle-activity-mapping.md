# Moodle Activity Mapping

| Module | Workflow | Possible completion condition |
|---|---|---|
| lesson | Navigate pages/branches to end | reach end / lesson rule |
| quiz | Create attempt, answer/submit as required | attempt / grade / passing grade |
| assign | Create and submit assignment | submission |
| feedback | Fill and submit form | response |
| resource | View resource/file | view |
| page | View page | view |
| h5pactivity | Perform H5P interaction | interaction / score |

## Priority for implementation
1. Resource/Page
2. Lesson
3. Feedback
4. Assignment
5. Quiz
6. H5P

The order moves from simpler view-based workflows toward stateful attempt/grade/interactive workflows.
